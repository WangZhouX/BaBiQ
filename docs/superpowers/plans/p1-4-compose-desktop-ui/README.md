# P1-4 Compose Desktop UI 计划目录

本目录用于承载 P1-4 桌面端 UI 阶段的详细计划、原型材料和交接信息。

## 目录结构

```text
p1-4-compose-desktop-ui/
├── README.md
├── plan.md
├── codex-handoff.md
└── prototype/
    ├── README.md
    ├── wireframes/
    ├── screens/
    ├── flows/
```

## 文件用途

- `plan.md`: P1-4 详细实施计划。正式实现前必须补全并经用户确认。
- `codex-handoff.md`: 给后续 Codex 执行者的入口摘要。
- `prototype/`: 原型投放区,用于放置别人产出的线框图、高保真图、交互流和参考材料。
