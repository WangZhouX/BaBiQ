## 待执行重点

1. 输入栏新增 P3 状态 chip：上下文占用、已压缩次数、长期记忆、能力按需装配。
2. 新增上下文状态弹层：展示当前窗口、阈值、active summary、长期记忆注入和分层 envelope。
3. 运行详情增加上下文快照、记忆引用、能力搜索等审计视图。
4. 设置页增加记忆管理。
5. 技能页升级为能力中心，区分 Local/MCP/Skill 和 default/deferred/disabled。
6. 新增中文能力搜索演示，体现 Lucene/BM25 + 中文别名 `searchText` 的用户可见价值。
7. 修正“成本”文案为 token/运行反馈，避免与 P2 后成本移除决策冲突。

## 剩余风险

- Figma 原型中存在旧版 292px 侧栏和新版 196px 侧栏混用，执行时需要统一视觉规格。
- 当前原型有些页面标题仍偏 P2，需要避免用户误以为 P3 能力只是设置页开关。
- 原型刷新不等于 Compose Desktop 已实现；如果后续要把这些页面接入桌面端，需要另开实现计划。
