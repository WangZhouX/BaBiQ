# 翔鸟律智桌面端壳层与小律助手改版设计

## 目标

把当前偏演示性质的“汇泰业务桌面 Agent”窗口升级为符合业务系统使用习惯的“翔鸟律智桌面端”：默认最大化、使用 Web 端品牌、以顶部导航承载一级入口，并用右下角吉祥物控制不遮挡业务内容的可停靠助手分栏。

## 已确认的产品决策

- 产品名称统一为“翔鸟律智桌面端”。
- 助手名称统一为“小律智能助手”；普通助手消息署名使用“小律”。
- Logo 使用 `E:/huitai-work/huitai-law-oa/src/assets/imgs/logo.png` 的 Web 正式资源。
- 吉祥物以用户提供的挥手律师鸟截图 `codex-clipboard-6ff65d30-ce78-4e1c-9931-69e3712eb3b9.png` 为唯一形象参考，制作去背景、居中裁切和高清放大的透明 PNG 派生资源；不改变角色、服装、动作、法槌或配色。派生资源作为桌面内置资源，不以代码依赖临时目录或 Web 工程绝对路径。
- 窗口启动时默认最大化，保留系统标题栏，因此仍可使用 Windows 的最小化、最大化/还原和关闭按钮。这里不采用会失去标准窗口控制的无边框独占全屏。
- 一级导航从左侧栏迁到应用顶部：品牌在左，工作台/资料录入/运行记录居中或顺序排列，设置固定在右侧。
- 取消收起后的 52dp Agent 竖栏；收起时只保留右下角吉祥物入口。
- 助手展开后采用推挤式可停靠分栏，不覆盖业务表单；关闭后业务区恢复全宽。

## 窗口与品牌

Compose `Window` 使用 `WindowPlacement.Maximized` 初始化，同时保留 1440×900 的默认还原尺寸和 1100×720 的最小窗口尺寸。窗口标题改为“翔鸟律智桌面端”，窗口图标与顶部品牌均加载打包后的 Web Logo。

品牌资源放入 `business-desktop/app/src/main/resources/brand/`，随 classpath 和安装包一起发布。运行时不读取 `E:/huitai-work/huitai-law-oa` 或用户临时目录，确保开发运行与安装包行为一致。

原生发布元数据也统一改版：MSI/EXE、开始菜单、桌面快捷方式和安装器的用户可见产品名使用“翔鸟律智桌面端”；Windows 原生图标使用由 Web Logo 生成并随仓库保存的多尺寸 `.ico`。若底层打包工具要求稳定的 ASCII 应用标识，则内部标识与用户可见 display name 分离，但任何用户可见位置不得继续出现 `HuitaiBusinessDesktop`。

## 顶部导航

新增独立 `BusinessTopNavigation` 组件，高度约 64dp：

- 左侧展示 32dp Logo 和“翔鸟律智桌面端”；
- 主导航展示“工作台”“资料录入”“运行记录”，沿用唯一 `BusinessDesktopDestination` 状态；
- “设置”作为右侧独立入口，选中时仍显示真实 Provider 设置页；
- 使用稳定 test tag 与 content description，不能只靠视觉文本定位；
- 小窗口下保持顶部导航，通过缩短间距和标签而不是恢复左侧栏。

`BusinessDesktopDestination.AGENT` 不再是用户可见的导航入口。助手始终由吉祥物控制，但保留现有会话、Provider、附件、审批和表单补丁状态链路。

## 小律助手停靠分栏

新增 `BusinessAssistantDockState` 与纯布局策略：

- 默认收起，初始宽度 460dp；
- 用户点击右下角吉祥物，切换为展开；再次点击吉祥物或点击面板头部“收回小律智能助手”按钮则收起；
- 展开时，内容区按“业务区 + 拖拽分隔条 + 助手区”排版，助手位于右侧、向左增宽，业务区同步缩窄，二者永不重叠；
- 拖动助手左侧分隔条改变宽度，宽度严格限制在 360–720dp；
- 布局策略始终为业务区保留至少 640dp；
- 调整后的宽度和展开状态由顶层 Compose 状态持有，面板重组、导航切换或收起再展开不会丢失；本阶段不跨应用重启持久化。

助手可展开的精确最小内容宽度为 `640 + 8 + 360 = 1008dp`（业务区 + 分隔条 + 助手）。当受操作系统可用屏幕、DPI 或测试容器限制，内容宽度仍小于 1008dp 时，点击吉祥物不会打开助手，而是显示“窗口宽度不足，请先最大化或放大窗口”的稳定提示；禁止回退为覆盖、把助手压到 360dp 以下，或把业务区压到 640dp 以下。

吉祥物资源至少输出 512×512 透明 PNG，Compose 以 104dp `ContentScale.Fit` 显示，并提供至少 112×112dp 点击热区。收起时固定在内容区右下角并避开页面主操作按钮；展开时放在助手右下侧、位于输入区上方至少 16dp 的安全位置，不能遮挡输入框、附件按钮或发送按钮。它始终作为切换按钮，并提供“打开小律智能助手”或“收回小律智能助手”的可访问语义。

## 助手面板

现有 `BusinessAgentPanel` 保留协议和业务能力，仅调整用户可见壳层：

- 标题改为“小律智能助手”；
- 收回按钮的可访问名称同步更新；
- 普通助手消息署名由“Agent”改为“小律”；
- `AgentComposer`、动作预览、连接提示、折叠语义等所有用户可见文案执行全量审计：“业务 Agent”“汇泰业务桌面 Agent”和面向用户的泛称“Agent”统一替换为“小律智能助手”或“小律”；内部类名、协议字段和稳定 test tag 不改名；
- test tag 可沿用稳定内部名，避免无必要破坏自动化；
- 连接状态、Provider/模型选择、会话消息、思考过程、计划、动作进度、TurnSummary、附件与输入框保持原功能。

## 响应式与错误边界

- 默认最大化是启动偏好，不锁死用户窗口；用户可以还原、缩放、最小化，最小窗口尺寸为 1100×720。
- 内容布局不再使用固定左导航宽度和收起 Agent rail；业务内容宽度等于可用宽度减去当前助手宽度与分隔条。
- 若品牌资源缺失，启动应快速失败或使用稳定的资源加载错误，不从任意本机路径回退。
- 拖拽宽度必须经过纯策略函数钳制，避免负宽度、助手越界或业务区被压缩到不可用。
- 分隔条视觉线宽约 1dp，但鼠标命中区域至少 12dp；悬停显示水平缩放光标，提供“调整小律智能助手宽度”的 content description，并在获得焦点后支持左右方向键以 16dp 步长微调。

## 测试与验收

1. 窗口配置测试：标题、默认最大化、默认还原尺寸与最小尺寸。
2. 品牌资源测试：Logo、透明高清吉祥物和 Windows `.ico` 可以从 classpath/仓库解码，且生产代码不含 Web 工程或 Temp 绝对路径。
3. 顶部导航 Compose 测试：品牌、主导航、顶部设置入口、选中状态与路由。
4. 停靠布局纯单元测试：收起全宽、展开不重叠、360–720dp 钳制、业务区至少 640dp、拖拽增减方向正确；内容宽度不足 1008dp 时拒绝展开并给出稳定提示。
5. Shell Compose 测试：默认只显示吉祥物；点击后出现“小律智能助手”，业务区宽度减少；拖拽或键盘微调后宽度变化；再次点击后业务区恢复全宽；吉祥物在展开/收起状态均不遮挡业务主操作和助手输入操作；不再出现左侧栏或 52dp Agent rail。
6. 助手面板测试：新标题、新收回语义和“小律”消息署名；源码/资源文案审计断言不再出现“汇泰业务桌面 Agent”“业务 Agent”等旧用户品牌文本。
7. 运行 `business-desktop` 聚焦测试和全量测试。
8. 真实前后端启动后进行最大化窗口、顶部导航、品牌图、吉祥物、展开/收回和拖拽宽度的视觉烟测。
9. 运行现有 `smokePackagedDistribution` 或等价的可分发目录/MSI 烟测，确认安装器/快捷方式/窗口的产品名与图标、classpath 品牌资源和助手交互在打包环境中均可用。

## 非目标

- 本阶段不重做业务表单视觉、不新增后台接口。
- 不跨重启保存助手宽度。
- 不做无边框自绘 Windows 标题栏。
- 不从 Web 服务在线下载 Logo 或吉祥物。
